# SmartRide Ticketing System

A Java console-based bus ticketing system developed as an academic project to manage passenger ticket bookings, cancellations, passenger search, and travel-time calculation.

## Project Overview

SmartRide Ticketing System is designed to demonstrate the use of Object-Oriented Programming, data structures, sorting algorithms, and matrix-based travel-time calculation in Java. The system provides a simple console-based solution for managing bus ticket operations.

## Features

- Passenger ticket booking
- Ticket cancellation
- Passenger search
- Ticket management
- Travel-time calculation between bus stops
- Sorting passengers by name
- Sorting travel-time related data
- Console-based user interaction

## Technologies Used

- Java
- Object-Oriented Programming
- Data Structures
- Sorting Algorithms
- Console Application

## Data Structures Used

- Queue for managing passenger bookings using FIFO order
- Stack for managing ticket cancellations using LIFO order
- 2D matrix for calculating travel time across bus stops

## Algorithms Used

- Bubble Sort
- Merge Sort

## Bus Stops Used

- Dehiwala
- Karagampitiya
- Kalubowila
- Kohuwala
- Nugegoda

## Project Purpose

The purpose of this project is to practice Java programming, Object-Oriented Programming concepts, data structures, sorting algorithms, and basic route-based travel-time calculation through a real-world bus ticketing scenario.

## How to Run

1. Download or clone this repository.
2. Open the project in a Java IDE such as Eclipse, VS Code, or NetBeans.
3. Run the main Java file from the IDE.
